# 📒 收支记账本（Accounting Book）

一个基于纯前端实现的轻量级记账应用，支持收入/支出记录、日历视图、分类管理与数据备份，适用于个人日常收支管理。

---

## ✨ 功能特性

### 🧾 基础记账
- 支持收入 / 支出记录
- 自定义金额与分类
- 自动格式化金额（保留两位小数）

### 📅 日历视图
- 按月查看账单
- 每日收支汇总展示
- 点击日期查看详情

### 📊 数据统计
- 本月收入 / 支出 / 结余
- 支持基础月度统计分析

### 🗂 分类管理
- 自定义收入 / 支出分类
- 支持编辑、删除与排序

### 🔍 搜索功能
- 支持按关键词、日期、金额筛选

### 💾 数据管理
- 基于 IndexedDB 本地存储
- 支持数据导入 / 导出
- 一键清空数据

### 📤 导出功能
- 导出为文本格式（便于分享）
- 支持按月份导出备份

### 🎨 UI 与体验
- 深色模式支持 🌙
- 可自定义主题（颜色 / 字体 / 间距）
- 移动端优化（支持 PWA 安装）

---

## 🛠 技术栈

- HTML5 + CSS3 + JavaScript（原生）
- IndexedDB（浏览器本地数据库）
- PWA（Progressive Web App）

> 无框架依赖，轻量、快速、可离线使用

## 💡 数据存储说明

- 数据存储于浏览器本地（IndexedDB）
- 不会上传至服务器
- 清除浏览器数据将导致数据丢失
- 建议定期进行数据导出备份

---

## ⚠️ 注意事项

- 最大记录数约 5000 条（用于控制性能）
- 不同设备之间数据默认不互通
- 建议定期备份数据

## 🧠 核心实现

### 数据存储

使用 IndexedDB 管理以下数据结构：

- `entries`（账单数据）
- `settings`（界面配置）
- `categories`（分类信息）

---

### 输入处理

- 自动过滤非法字符
- 限制两位小数
- 实时格式化金额输入

---

### UI 设计

- 卡片式布局
- 动画过渡效果
- 深色模式适配
