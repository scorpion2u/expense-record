收支记账本 - 移动端个人财务管理工具
📱 项目简介
这是一款专为移动端设计的个人收支记账应用，采用纯 HTML/CSS/JavaScript 开发，无需任何框架依赖。应用支持记录日常收支、查看月度统计、分类管理、数据导入导出等功能，界面简洁美观，适配深色模式。

✨ 主要功能
📊 记账核心功能
收支记录：快速记录支出/收入，支持金额、分类、支付方式（TNG、现金、信用卡、借记卡）

餐饮份数：早餐/午餐/晚餐自动弹出份数选择，方便记录用餐人数

日历视图：直观展示每日收支情况，支持月份切换和滑动操作

今日明细：展示当天记录，支持编辑、删除操作

📈 数据统计
月度概览：顶部卡片显示本月收入、支出、结余

月度统计：详细的月度收支分析和支付方式占比

搜索功能：按关键词、日期范围、金额、类型多维度筛选

🎨 个性化设置
深色模式：一键切换亮色/暗色主题

界面定制：自定义支出/收入颜色、卡片背景、字体大小、间距等

HSL 调色：精细调节颜色色相、饱和度、亮度

📁 数据管理
本地存储：所有数据保存在浏览器 localStorage

导出笔记：生成格式化的文字账单，一键复制分享

备份导出：支持按月份/类型筛选导出 JSON 备份文件

备份导入：支持合并或替换模式导入备份数据

分类管理：自定义收支分类，支持拖拽排序、编辑、删除

🚀 快速开始
克隆或下载本项目

bash
git clone <仓库地址>
直接打开 index.html

双击文件即可在浏览器中运行

推荐使用移动端浏览器或 Chrome 开发者工具的移动设备模拟

添加到主屏幕（PWA 体验）

在 iOS Safari 或 Android Chrome 中选择"添加到主屏幕"

📖 使用指南
添加记录
选择日期（点击日历格子）

切换支出/收入类型

输入金额

选择或输入分类

按回车或点击分类确认，选择支付方式完成记账

查看统计
点击顶部卡片查看本月对应类型的详细记录

点击菜单 → "月度统计" 查看完整分析

导出笔记
菜单 → "导出笔记"

选择月份后生成格式化文本，可一键复制分享

备份与恢复
菜单 → "导出备份" 保存数据到 JSON 文件

菜单 → "导入备份" 恢复之前保存的数据
