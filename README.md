# 📒 收支记账本（Accounting Book）

一个基于纯前端实现的轻量级记账应用，支持收入/支出记录、日历视图、分类与支付方式管理、数据备份，适用于个人日常收支管理。支持中英文双语切换和多货币符号显示。

---

## ✨ 功能特性

### 🧾 基础记账
- 支持收入 / 支出记录
- 自定义金额与分类
- 支持多种支付方式（现金、电子钱包、信用卡等）
- 支持收款方式管理（现金、电子钱包、银行转账等）
- 餐类（早/午/晚餐）自动弹出份数选择
- 自动格式化金额（保留两位小数）

### 📅 日历视图
- 按月查看账单
- 每日收支汇总展示
- 点击日期查看详情
- 支持农历显示（中文模式）
- 左右滑动切换月份

### 📊 数据统计
- 本月收入 / 支出 / 结余
- 支付方式 / 收款方式分类统计
- 点击统计卡片快速搜索

### 🗂 分类管理
- 自定义收入 / 支出分类
- 支持编辑、删除与拖拽排序
- 存储与显示分离，切换语言不影响数据

### 💳 支付方式管理
- 自定义支出支付方式
- 自定义收入收款方式
- 支持编辑、删除与拖拽排序

### 🔍 搜索功能
- 支持按关键词、日期范围、金额范围筛选
- 支持按收支类型筛选
- 搜索结果可点击跳转到对应日期

### 💾 数据管理
- 基于 IndexedDB 本地存储
- 支持数据导入 / 导出（含分类和支付方式）
- 支持按月份导入 / 导出
- 合并模式自动去重
- 一键清空数据（三步确认）

### 📤 导出功能
- 导出为文本格式（便于分享）
- 支持按月份导出笔记
- 一键复制到剪贴板

### 🎨 UI 与体验
- 深色模式支持 🌙
- 可自定义主题（支出颜色 / 收入颜色 / 卡片底色 / 页面背景色）
- 可调间距、内边距、字体大小
- 移动端优化（支持 PWA 安装）
- 返回顶部浮动按钮

### 🌐 国际化
- 支持简体中文 / English 切换
- 存储数据不受语言切换影响
- 多货币符号显示（MYR、CNY、USD、SGD 等 16 种）

## 🚀 使用方式

###🌐 在线体验
👉 https://scorpion2u.github.io/expense-record

- 📲 安装为应用（PWA）
在浏览器中打开后：

- 点击菜单 →「📱 安装应用」

- 或在浏览器菜单中选择「添加到主屏幕」

###💡 数据存储说明
- 数据存储于浏览器本地（IndexedDB）不会上传至任何服务器
- 清除浏览器数据将导致数据丢失
-建议定期进行数据导出备份

###⚠️ 注意事项
- 最大记录数约 5000 条（超过自动清理最旧记录）
- 不同设备之间数据默认不互通
- 建议定期备份数据
- 分类和支付方式以中文存储，切换语言仅影响显示

###🧠 核心实现
- 数据存储
- 使用 IndexedDB 管理以下数据结构：
- 存储内容:
* entries = 账单记录（含金额、分类、支付方式、备注、时间戳）
* settings = 界面配置（颜色、间距、暗色模式、语言、货币）
* categories= 分类与支付方式（支出分类、收入分类、支付方式、收款方式）
- 输入处理 = 自动过滤非法字符，限制两位小数和实时格式化金额输入
- 分类输入支持下拉选择与手动输入

### 国际化设计
- 翻译数据与业务逻辑分离
- 分类/支付方式：存储中文原始值，显示时根据语言翻译
- translateNote() 处理复合备注（"分类 · 备注"）

### UI 设计
- 卡片式布局
- 动画过渡效果
- 深色模式全适配
- HSL 颜色调节器（色相/饱和度/亮度）
