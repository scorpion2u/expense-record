📒 收支记账本（Accounting Book）

一个纯前端实现的轻量级记账应用，支持收入/支出记录、日历视图、分类管理、数据备份等功能，适合个人日常记账使用。

---

✨ 功能特性

🧾 基础记账

- 支持 收入 / 支出 分类记录
- 自定义金额与分类
- 自动格式化金额输入（保留两位小数）

📅 日历视图

- 按月查看账单
- 每天显示收支汇总
- 点击日期查看当日详情

📊 数据统计

- 本月收入 / 支出 / 结余
- 支持月度统计分析

🗂 分类管理

- 支持自定义收入/支出分类
- 分类可编辑 / 删除 / 排序

🔍 搜索功能

- 按关键词、日期、金额筛选记录

💾 数据管理

- 本地存储（IndexedDB）
- 支持数据导出 / 导入
- 一键清空数据

📤 导出功能

- 导出为文本（便于分享）
- 按月份导出备份

🎨 UI 与体验

- 支持深色模式 🌙
- 可自定义主题（颜色、间距、字体等）
- 移动端优化（PWA 支持，可安装为 App）

---

🛠 技术栈

- HTML5 + CSS3 + JavaScript（原生）
- IndexedDB（本地数据库存储）
- PWA（Progressive Web App）
- 无任何框架依赖（轻量、快速）

---

💡 数据存储说明

- 所有数据存储在浏览器本地（IndexedDB）
- 不会上传到服务器，所以无需担心数据泄露
- 清除浏览器数据会导致数据丢失
- 建议定期使用“导出备份”功能

---

⚠️ 注意事项

- 最大记录数限制：约 5000 条（防止性能问题）
- 建议定期备份数据
- 不同设备之间数据不互通（除非手动导入）
